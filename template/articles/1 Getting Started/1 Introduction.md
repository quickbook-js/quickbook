# Welcome to Quickbook

This is your first lesson! Edit or add Markdown files inside the `articles/` directory to create your book.

## Features

- **Markdown Support**: Write in standard Markdown.
- **Fast Development**: Powered by Vite and Sugar High syntax highlighting.
- **GitHub Pages**: Deploys cleanly to GitHub Pages out of the box.
